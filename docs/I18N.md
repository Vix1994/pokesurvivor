# 语言与翻译维护

游戏支持西班牙语 `es`、英语 `en` 和简体中文 `zh-CN`。

- 登录页面有语言下拉菜单；登录后可在「设置 → 画面 → 语言」切换。
- 优先使用 `localStorage['ps.lang']`；其次使用 `/en/` 入口；否则识别浏览器首选语言。中文浏览器使用简体中文，西班牙语浏览器使用西班牙语，其他语言使用英语。
- 切换时仅写入语言设置，等待已有云端存档同步后刷新。对局、暂停和结算期间会阻止切换，请先回到主菜单。
- 翻译数据随游戏分发，无需在线翻译服务；昵称等用户内容通过 `translate="no"` 保持原样。存档中的宝可梦编号和原始数据不变。
- 独立的指南、图鉴与其他 SEO 页面仍由现有西班牙语 / 英语生成器维护。

## 添加翻译

`js/core/language.js` 统一维护语言列表和检测规则，加载画面与游戏共用。
`js/core/i18n.js` 处理 DOM、可访问性属性、Canvas 绘制与测量，以及浏览器对话框。

词典以西班牙语原文作为键：

```js
G.I18n.add({
  'Continuar': '继续',
  'Pregunta {x} de {x}': '第 {x} 题，共 {x} 题'
}, 'zh-CN');
```

游戏只注册当前语言的词典，避免多个语言词典互相覆盖。
`{x}` 按原文顺序替换，翻译必须保留占位符数量和参数顺序。
`js/data/lang-zh-CN.js` 包含游戏文本与更新日志；`js/data/pokemon-names-zh-CN.js` 包含全部可玩宝可梦名称，来自 PokeAPI 的简体中文物种名称数据。
新语言需要在 `language.js` 注册，在 `dev.html` 添加词典脚本，并为初始加载画面补充文本。`index.html` 为生成文件。

## 验证与构建

```sh
node --test tools/test_i18n.js
node tools/build.js
node tools/export_data.js
python tools/make_seo_pages.py
```

SEO 生成器需要 Python 3.12 或更新版本（现有代码使用新版 f-string 语法）。
回归测试覆盖语言检测、词典隔离、占位符、宝可梦名称、历史日志、Canvas 文本，以及切换时的存档同步与对局保护。

浏览器检查可运行 `python -m http.server 8765`，打开 `http://localhost:8765/dev.html` 或生成的 `index.html`，以游客身份完成性格测试，检查主菜单、图鉴、设置、升级卡牌和战斗 HUD，并确认中英西三种语言可切换。
